# Salo Urgente - Marketplace de Serviços Angola

## 🚀 Sobre o Projeto
Salo Urgente é um marketplace de serviços locais focado no mercado angolano, conectando clientes a prestadores de serviço da própria região.

## ✨ Funcionalidades
- ✅ Autenticação com Firebase
- ✅ Lista de prestadores
- ✅ Favoritos
- ✅ Reporte de problemas via WhatsApp
- ✅ Perfil do utilizador
- ✅ Design premium mobile-first

## 🛠️ Tecnologias
- Firebase (Auth, Firestore)
- HTML/CSS/JavaScript
- Font Awesome
- Google Fonts (Inter)
